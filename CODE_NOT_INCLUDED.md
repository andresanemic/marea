# Code not included

This public repository contains Marea's agreement, documentation and recorded evidence, but not its source code. The walkthrough and test records describe the behavior that was run; they do not make this repository an executable release.

The agreement says the code opens during the judges' review period under the review-only license. Judges and community reviewers may read and clone it for evaluation under that license. The license itself is unchanged and controls the permitted use; this page summarizes the publication boundary.

Until source code is included, readers can review the project through [How it works](./docs/HOW_IT_WORKS.md), compare its claims with [Evidence](./docs/EVIDENCE.md), and read the exclusions in [Legal and limits](./docs/LEGAL_AND_LIMITS.md). The recorded suite result is tied to the kernel cut and digest described in Evidence, not a guarantee that the source will run unchanged against a later installed kernel.

# Código no incluido

Este repositorio público contiene el acuerdo, la documentación y la evidencia registrada de Marea, pero no su código fuente. El recorrido y los registros de pruebas describen el comportamiento que se ejecutó; no convierten este repositorio en una versión ejecutable.

El acuerdo establece que el código se abrirá durante el periodo de revisión de los jueces bajo la licencia de solo revisión. El jurado y quienes revisen de la comunidad podrán leerlo y clonarlo para evaluarlo según esa licencia. La licencia no se modifica y determina los usos permitidos; esta página resume el límite de publicación.

Mientras el código no esté incluido, puedes revisar el proyecto en [Cómo funciona](./docs/HOW_IT_WORKS.md), contrastar sus afirmaciones con [Evidencia](./docs/EVIDENCE.md) y leer las exclusiones en [Marco legal y límites](./docs/LEGAL_AND_LIMITS.md). El resultado registrado de la suite está ligado al corte y digest del kernel descritos en Evidencia; no garantiza que el código corra sin cambios contra una versión instalada posterior.
