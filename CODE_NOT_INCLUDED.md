# Código no incluido

Este repositorio público contiene por ahora la documentación y la evidencia registrada de Marea, no su código fuente. El código se abrirá durante el periodo de los jueces bajo la licencia de solo revisión: el jurado y la comunidad podrán leerlo y clonarlo para evaluarlo.
